# Learning Profile V1 — 多維證據與平衡型自適應策略

## 已確認要求
- 本地長期保存：SQLite (`.taiwan-learning-data/learning.sqlite3`)；不連網、不建立中央服務。
- 智慧判斷初次診斷；先協助解題，不強制每個單元都先測驗。
- 各知識點記錄 L1-L4 教學建議、作答證據、判定可信度；證據不足保持未知。
- 錯誤類型：`concept`, `method`, `reading`, `calculation`, `units`, `reasoning`, `unknown`。
- 按錯誤類型、掌握狀態、最近表現安排下次複習，**不**主動發送提醒。
- 平衡型自適應：偶爾挑戰，不因單次答錯降級，不把答對率當作唯一判準。

## V1 規則（暫定啟發式，非心理計量效度模型）

- `未評估`: 尚無已驗證題目的作答紀錄；低可信證據不能直接標示 L1。
- `學習中`: 有有效作答但沒有兩道不同題目獨立答對。
- `初步掌握`: 至少兩道不同已驗證題目，在無提示下答對。
- `穩定掌握`: 至少四道不同題目獨立答對、涵蓋兩種題型、兩種情境、兩個不同日期，且最近三筆未重複答錯。
- `需要複習`: 曾有至少三道不同題目獨立答對，最近三筆有兩筆以上答錯。
- `可信度`: 由已驗證題數、題型多樣性、情境及日期判定。對應顯示詳細證據；不得用百分比偽裝測驗準確度。
- `L1–L4`: 是 Tutor 教學深度建議，不是固定學力或學生標籤。L4 需要已穩定掌握且多道高階題自主答對。

## 調整規則

- 觀念錯：Tutor 先查先備概念、釐清迷思，再由 Designer 出改變情境的驗證題。
- 單純計算失誤：保留觀念難度，重點安排符號/單位/運算練習。
- 提示後答對：保留難度，降低提示量；不等同自主掌握。
- 不同形式皆能獨立答對：適度提高難度或加入跨情境題。
- 單次答錯：不直接降級；可以先詢問是否看錯題目或有其他原因。
- 學生能查看、匯出和刪除自己的學習紀錄。

## 誠實限制

命令列的 `record` 會接受 Agent 提供的 `is_correct` 和 `question_verified`。工具不會自動判定學生作答是否正確；Agent 必須先按可信答案完成批改，不能把自行聲明當作獨立驗證。
