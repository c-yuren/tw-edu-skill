# 台灣國高中課綱對齊指引

- 分辨國中 (七、八、九年級) 和高中 (十至十二年級)；高中注意普通型、技術型及選修課程差異。
- 對單元的對齊資料：`grade`, `subject`, `unit`, `knowledge_point_id`（自訂 ID）, `official_learning_content_code`（有查證才填）, `official_learning_performance_code`（有查證才填）, `prerequisites`, `source_url`, `checked_at`。
- 不能將自訂 `knowledge_point_id` 冒稱官方課綱代碼。未核對原文時，官方課綱代碼填 `unverified`。
- 例如自訂 ID `HS-PHY-N2-FREEBODY` 代表高中物理受力圖，僅是系統標籤，**不是**官方代碼。
- 學測自然科的物理內容 ≠ 分科物理的完整範圍；依考試說明核對實際範圍。
- 題目先確認先備知識，再依學生目前理解程度調整方法，不因年齡/年級推定實際能力。
