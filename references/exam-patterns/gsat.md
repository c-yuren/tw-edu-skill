# 學測（GSAT）命題特徵：供 Agent 使用的分析方向

來源：https://www.ceec.edu.tw/ 及 https://www.ceec.edu.tw/xmdoc?xsmsid=0J018585845010094026

這是**質性命題特徵索引**，不是保證每年必出的題型、比例、頻率或官方完整命題規範。特定年份的正式規格需另行核對大考中心資料。

| 考科 | 可觀察與分析的命題特徵 | 設計要求 |
|---|---|---|
| 國文（國綜） | 古今文本閱讀、文意整合、推論、比較與語文知識 | 題幹需有可推論依據；不得靠模糊語感製造歧義 |
| 國寫 | 閱讀引導的知性/情意表達、觀點及論證 | 作文必設多向度評分規準，不以單一標準答案限制表達 |
| 英文 | 文字語境中的字彙文法、篇章理解、閱讀推論、寫作與翻譯 | 檢查語法、文本合理性和多個選項是否同時可接受 |
| 數學 A | 基本概念到多步推理、代數/幾何/跨單元整合 | 重點是數學結構與推理，不能用單純增加計算量冒充高難度 |
| 數學 B | 生活資訊轉譯、圖表及情境中的數學概念 | 情境資料需真正在解題中有用，避免無關長篇敘述 |
| 社會 | 史料/地圖/數據解讀、歷史地理公民整合、論證 | 要求資訊判讀和脈絡判斷；核對史實及資料來源 |
| 自然 | 實驗/圖表/測量資料、科學概念應用、跨科推理 | 物理/化學/生物/地科範圍核對；物理題不直接照分科物理命題 |

每次指定學測模考：
1. 確認年份及考科的官方範圍、題型、混合題、配分；題組須保留共同材料與分題關係。
2. 過去單一年份的比例不得硬編成永遠固定標準；最近三至五年的實際趨勢可作*觀察*，需有可核對資料。
3. 命題藍圖先交代測驗能力與題型理由；禁止只有「學測風格」「素養題」等空泛字眼。
4. 輸出標示「AI 原創模擬題，非大考中心原題或官方預測題」。
